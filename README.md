# Linux.do Keyword Blocker

Linux.do 帖子屏蔽脚本。用「类别 / 标签 / 标题」规则自动隐藏/淡化不想看的帖子。

## 安装

**方式一**：点击直装 → [Linux.do Keyword Blocker](https://github.com/Yesbaiwan/linuxdo-keyword-blocker/raw/main/ld-blocker.user.js)

**方式二**：手动复制 [ld-blocker.user.js](ld-blocker.user.js) 内容到 Tampermonkey 新建脚本

## 使用

1. 打开 linux.do 并**登录**——脚本强制登录后才工作，未登录时不过滤、也没有任何入口
2. 点击右上角**自己的头像**
3. 在弹出面板的标签列最底部（「个人资料」下面）找到**屏蔽规则**按钮
4. 点击后菜单内容区切换为规则管理界面（和原生通知面板同一块区域），在这里勾选「启用屏蔽」总开关、添加规则、切换处理模式
5. 添加规则：类别很多，直接在「类别」框里输入名称（如「开发调优」）即可实时过滤下拉，点选目标分类；标签或标题填写包含即命中（大小写不敏感），**至少填一项**，点击「添加规则」立即生效
6. 管理已有规则：每条规则可单独勾选启用/停用，点「编辑」会在该行下方展开同款表单原位修改（类别/标签/标题），「保存修改」或「取消」都在本行完成，「×」删除

规则生效条件 = 总开关「启用屏蔽」打开 **且** 该规则自身勾选启用。只开总开关、规则全部停用，等于没有任何规则生效。

### 匹配逻辑

一条规则内已填的字段必须**全部命中**才算命中，未填的字段不参与：

| 规则填法                      | 效果                                                       |
| ----------------------------- | ---------------------------------------------------------- |
| 仅类别「开发调优」            | 只屏蔽直接发在「开发调优」下的帖子（不带等级，不含子分类） |
| 仅类别「开发调优 Lv1」        | 只屏蔽发布在「开发调优 Lv1」子分类的帖子（Lv2/Lv3 同理）   |
| 仅标题「opencode」            | 屏蔽标题含 opencode 的帖子                                 |
| 标签「人工智能」+ 标题「GPT」 | 屏蔽标签含人工智能**且**标题含 GPT 的帖子                  |
| 类别+标签+标题全填            | 三者都满足才屏蔽                                           |

类别按站点的类别 ID **精确匹配所选分类本身**：下拉里父分类和各级子分类（Lv1/Lv2/Lv3…）都是独立选项，选哪个就只屏蔽哪个，父分类不会连带子分类——有子分类的分类在选项和规则行文本里都会标注「（不带等级）」，即只屏蔽直接发在该分类下的帖子；首项「不按类别筛选」表示该规则不看类别。屏蔽某个大类的全部帖子建议直接用 Discourse 自带的「静音分类」——大范围屏蔽会让信息流大量消失，站点不停加载新帖甚至触发限流。标签与标题按文字包含匹配。旧版本的关键词列表会自动迁移为仅标题规则。

### 管理界面功能

| 控件        | 说明                                                   |
| ----------- | ------------------------------------------------------ |
| 启用屏蔽    | 总开关（与单条规则的勾选同时打开才生效）               |
| 处理        | 切换隐藏/淡化模式，默认「淡化显示」                    |
| 类别        | 可搜索的类别选择框：输入即过滤、点选即选中，× 清除已选 |
| 标签/标题   | 规则的文字字段（包含即命中）                           |
| 添加规则    | 新增当前填写的一条规则                                 |
| 规则勾选    | 单条规则的启用/停用（停用的画删除线）                  |
| 规则 编辑/× | 在该行下方展开表单原位修改 / 删除单条规则              |
| 导出        | 下载规则列表（JSON）                                   |
| 清空        | 清除所有规则                                           |
