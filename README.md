# Linux.do Keyword Blocker

Linux.do 帖子屏蔽油猴脚本。用「类别 / 标签 / 标题」筛选自动隐藏/淡化不想看的帖子。

## 安装

> 需要安装浏览器 Tampermonkey 插件，自行搜索教程。

已有 Tampermonkey 插件，安装方式有两种：

**方式一**：点击直装 → [Linux.do Keyword Blocker](https://github.com/Yesbaiwan/linuxdo-keyword-blocker/raw/main/ld-blocker.user.js)

**方式二**：手动复制 [ld-blocker.user.js](ld-blocker.user.js) 内容到 Tampermonkey 新建脚本

## 使用

1. 脚本强制登录 Linux.do 后才工作，未登录时不过滤、也没有任何管理入口
2. 点击右上角**自己的头像**
3. 在弹出面板的标签列最底部（「个人资料」下面的漏斗图案）找到**屏蔽规则**按钮（和原生通知面板同一块区域）
4. 勾选「启用屏蔽」总开关、添加规则、切换处理模式
5. 添加规则：类别是固定的，直接在下拉框选择；标签或标题填写包含即命中（大小写不敏感），**至少填一项**，点击「添加规则」立即生效
6. 管理已有规则：每条规则可单独勾选启用/停用，点「编辑」会在该行下方展开同款表单原位修改（类别/标签/标题）

### 匹配逻辑

一条规则内已填的字段必须**全部命中**才算命中，未填的字段不参与，示例：

| 规则填法                      | 效果                                                       |
| ----------------------------- | ---------------------------------------------------------- |
| 仅类别「开发调优」            | 只屏蔽直接发在「开发调优」下的帖子（不带等级，不含子分类） |
| 仅类别「开发调优 Lv1」        | 只屏蔽发布在「开发调优 Lv1」子分类的帖子（Lv2/Lv3 同理）   |
| 仅标题「opencode」            | 屏蔽标题含 opencode 的帖子                                 |
| 标签「人工智能」+ 标题「GPT」 | 屏蔽标签含人工智能**且**标题含 GPT 的帖子                  |
| 类别+标签+标题全填            | 三者都满足才屏蔽                                           |

### 功能

| 控件         | 说明                                                   |
| ------------ | ------------------------------------------------------ |
| 启用屏蔽     | 总开关（与单条规则的勾选同时打开才生效）               |
| 模式         | 切换隐藏/淡化模式，默认「淡化显示」                    |
| 类别         | 可搜索的类别选择框：输入即过滤、点选即选中，× 清除已选 |
| 标签/标题    | 规则的文字字段（包含即命中）                           |
| 添加规则     | 新增当前填写的一条规则                                 |
| 规则启用     | 单条规则的启用/停用（停用的画删除线）                  |
| 编辑已有规则 | 在该行下方展开表单原位修改 / 删除单条规则              |
| 导出         | 下载规则列表（JSON）                                   |
| 清空         | 清除所有规则                                           |
