# Linux.do Keyword Blocker

Linux.do 关键词屏蔽脚本。按关键词自动隐藏/淡化不想看的帖子。

## 安装

1. 安装用户脚本管理器（推荐 [Tampermonkey](https://www.tampermonkey.net/)）
2. 点击安装：[ld-blocker.user.js](ld-blocker.user.js)
3. 或手动复制 `ld-blocker.user.js` 内容到 Tampermonkey 新建脚本

## 使用

1. 打开 linux.do 任意页面
2. 右上角出现「屏蔽词」按钮，点击打开面板
3. 勾选「启用屏蔽」
4. 输入关键词（逗号分隔），点击「添加」
5. 选择模式：「直接隐藏」或「淡化显示」
6. 匹配的帖子立即生效

### 面板功能

| 按钮 | 说明 |
| ---- | ---- |
| 启用屏蔽 | 总开关 |
| 添加 | 添加输入框里的关键词 |
| 处理 | 切换隐藏/淡化模式 |
| 导出 | 下载关键词列表 |
| 还原位置 | 按钮重置到右上角 |
| 清空 | 清除所有关键词 |
| × | 删除单个关键词 |

- 按钮可拖拽移动，位置自动保存
