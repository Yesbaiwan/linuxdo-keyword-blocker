# Linux.do Keyword Blocker

Linux.do 帖子屏蔽油猴脚本：用「类别 / 标签 / 标题」规则自动隐藏或淡化不想看的帖子。纯 DOM API、无依赖，只面向桌面 Chrome。

## 安装

需要浏览器已装 Tampermonkey。

- 直装：[ld-blocker.user.js](https://github.com/Yesbaiwan/linuxdo-keyword-blocker/raw/main/ld-blocker.user.js)
- 手动：复制 [ld-blocker.user.js](ld-blocker.user.js) 内容到 Tampermonkey 新建脚本

## 使用

需要已登录 Linux.do；未登录时不过滤、也不显示任何界面，登录后自动生效。

- **打开面板**：`Ctrl+Q`，或 Tampermonkey 菜单里的「屏蔽规则」；`Esc` / 点 × / 点遮罩空白关闭。
- **总开关 / 处理模式**：需「启用屏蔽」总开关与该条规则的勾选同时打开才生效；处理模式「隐藏 / 淡化」，默认淡化。
- **添加规则**：至少填「类别 / 标签 / 标题」中的一项，点「添加规则」立即生效。
- **管理规则**：每行可单独启停（停用画删除线）、点「编辑」在该行下方原位修改、× 删除。
- **导入 / 导出**：导出为 JSON 规则数组，导入同一格式（会替换现有全部规则）。
- **清空**：删除所有规则。

## 匹配逻辑

一条规则里**已填的字段必须全部命中**（AND）才算命中，未填字段不参与；任一规则命中即处理该行。均大小写不敏感。

| 字段   | 匹配方式                                                                                                               |
| ------ | ---------------------------------------------------------------------------------------------------------------------- |
| 类别   | 按徽章 `data-category-id` 精确匹配所选分类本身，默认不连带子分类；选「（所有等级）」则同时命中该分类及其全部等级子分类 |
| 标签   | 按标签文字精确匹配（子串不命中），一条规则最多 3 个，需全部存在                                                        |
| 无标签 | 只命中零标签的帖子（与标签互斥）                                                                                       |
| 标题   | 包含即命中                                                                                                             |

示例：仅类别「开发调优」只屏蔽直接发在该分类下的帖子；类别选「开发调优（所有等级）」再配标签「人工智能」，则只屏蔽该分类各级中带此标签的帖子。

## 开发说明

- 环境：Windows 11 + Node.js，测试用 playwright-core 驱动本机 Chrome。
- 项目根目录需放 `linux.do_cookies.txt`（linux.do 的 cookie），经常需要更换。
