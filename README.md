# Linux.do Keyword Blocker

Linux.do 关键词屏蔽脚本。按关键词自动隐藏/淡化不想看的帖子。

## 安装

**方式一**：点击直装 → [Linux.do Keyword Blocker](https://github.com/Yesbaiwan/linuxdo-keyword-blocker/raw/main/ld-blocker.user.js)

**方式二**：手动复制 [ld-blocker.user.js](ld-blocker.user.js) 内容到 Tampermonkey 新建脚本

## 使用

1. 打开 linux.do 页面，点击右上角**自己的头像**
2. 在弹出面板的标签列最底部（「个人资料」下面）找到**屏蔽词**按钮
3. 点击后菜单内容区切换为关键词管理界面（和原生通知面板同一块区域），在这里勾选「启用屏蔽」、添加关键词、切换处理模式
4. 输入关键词（逗号分隔），点击「添加」，匹配的帖子立即生效
5. 未登录时没有头像入口，可通过 Tampermonkey 菜单里的「打开 Linux.do 屏蔽词设置」**直接弹出一个独立的悬浮设置面板**（点面板外或 × 关闭）；已登录用户也可以这样打开，或继续使用头像菜单里的「屏蔽词」标签

### 管理界面功能

| 控件     | 说明                                 |
| -------- | ------------------------------------ |
| 启用屏蔽 | 总开关                               |
| 添加     | 添加输入框里的关键词（支持逗号批量） |
| 处理     | 切换隐藏/淡化模式                    |
| 关键词 × | 删除单个关键词                       |
| 导出     | 下载关键词列表                       |
| 清空     | 清除所有关键词                       |
