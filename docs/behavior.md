# 行为契约

脚本对外的表现与判定规则。改 `ld-blocker.user.js` 前先读这份；实现细节见 [internals.md](internals.md)，必须遵守的写法见 [constraints.md](constraints.md)。

## 启动与入口

- **只对已登录页面生效**：页面头部有 `#current-user` 才启动（本站实测该元素登录后才有）。未登录时不过滤、也不显示任何 UI。
- **SPA 登录也能启动**：未登录时挂观察器等登录，登录不刷新页面。
- **两个入口**：Tampermonkey 菜单命令「屏蔽规则」，或快捷键 `Ctrl+Q`；`Ctrl+Q` 是开合切换。
- **面板**：遮罩居中的 540px 卡片，挂在 `body` 上常驻；`Esc`、点遮罩空白、点 `×` 都能关闭，关闭时复位编辑态。
- **重复注入不叠加**：脚本带幂等守卫，同一文档注入多次只生效一份（见 [internals.md](internals.md)）。

## 面板

### 总开关

面板顶部的「启用屏蔽」总开关，与每条规则自身的勾选是两回事：**两者同时打开**该规则才生效。总开关或规则全关时，页面上已落的状态会被清理掉。

### 添加 / 编辑表单

- 一条规则 = 类别下拉 + 标签 + 标题，**至少填一项**；全空视为无效。
- 与现有规则重复时状态行提示，且表单内容保留（不清空），可直接改条件再提交。
- 标签：**默认 1 个框**，点「+」增设至多 3 个；每框一个标签（不按逗号切分），每框可 `×` 移除；只剩 1 个框时不给 `×`（避免整组被清空）。
- 「零标签」复选框在标签行内，勾选后标签框与「+」收起（复选框本身保留）。
- 行内编辑在本行下方展开，与添加表单同一套字段与排版，差异只在按钮。
- **Enter 提交只作用于标签组与标题**，不作用于类别输入框——后者有自己的回车选中语义。

### 规则列表

- **单规则启停**：停用的规则画删除线。
- **批量启停**：页脚左组「清空」旁的降权文字按钮，文字显示将执行的动作——全开时显「全部停用」，否则（含混合状态）显「全部启用」；完全可逆、无需确认；0 条规则时禁用。
- **任何重建列表的操作**（添加 / 删除 / 清空 / 保存、类别树就绪）都会收起编辑表单；只有单规则启停是就地更新（不重建列表，展开中的编辑表单不受影响）。
- 已添加规则的搜索刻意不做。
- 导入结果这类一次性提示会短暂占用状态行，到时恢复常规文案。

### 类别下拉

- 外观同普通下拉框（右侧三角，点一下开、再点一下收），但保留输入即过滤——站点分类含各等级共 80+ 项，纯 select 翻找太累。
- **输入即过滤**；`↑` / `↓` 移动高亮，高亮行会自动滚进浮层可视区；到两端绕回另一端；回车选中高亮行，没有高亮时取第一个真实类别；鼠标划过也同步高亮。
- 点选或点 `×` 清除；失焦恢复原值。
- 搜索词是临时的：失焦未选择则恢复原值，只有显式点选或点 `×` 清除才改变选中结果。
- 候选列表是 fixed 浮层，贴输入框上下方展开（不参与面板布局，展开不撑高面板）。
- **拉取失败时下拉里给重试入口**：状态行提示，下拉底部一条「点此重试」，点它重新拉一次再刷新候选。

### 处理模式

「隐藏 / 淡化」两种，**默认淡化**。

### 导入 / 导出 / 清空

- **导入 / 导出**：同一份格式的规则数组 JSON。导出直接给规则数组；导入为**追加**模式——文件内部重复、与现有规则重复都跳过，只收新规则；全空规则直接丢、不计入重复；提示里带跳过计数。
- **清空**：页脚左端的降权文字按钮，与右侧导入 / 导出拉开距离。两段式确认防误触——首击进红色确认态、**3 秒无操作 / 列表重建 / 关面板**任一发生即自动复位、再击才执行；0 条规则时禁用。

## 过滤范围

- 首页 / 最新 / 未读 / 热门 / 分类列表页（`tr.topic-list-item` 等）与搜索结果页（`.fps-result`）。
- 搜索结果内层也带 `data-topic-id`，状态只打最外层行，内层清空（Ember 会回收复用行节点，残留状态要清掉）。
- **子分类页面行内无类别徽章**，所以类别规则在那类页面天然不命中。

## 匹配语义

规则内**已填字段必须全部命中**（AND）才算命中，未填字段不参与；任一规则命中即处理该行。均大小写不敏感。

| 字段   | 匹配方式                                                                                                              |
| ------ | --------------------------------------------------------------------------------------------------------------------- |
| 类别   | 按徽章 `data-category-id` 数字精确匹配所选分类**本身**，默认不连带子分类；选「（所有等级）」则覆盖自身 + 全部等级后代 |
| 标签   | 按 `a.discourse-tag` 文字精确匹配（子串不命中）；一条规则最多 3 个，需全部存在                                        |
| 零标签 | 只命中零标签帖（与标签互斥，勾选后不保留标签）                                                                        |
| 标题   | 包含即命中                                                                                                            |

示例：仅类别「开发调优」只屏蔽直接发在该分类下的帖子；类别选「开发调优（所有等级）」再配标签「人工智能」，则只屏蔽该分类各级中带此标签的帖子。

## 存储

```js
{ enabled, rules: [{ category, allLevels, tags, noTag, title, enabled }], hideMode }
```

只认这一种格式。形状不对（手改存储 / 导入非数组 JSON）一律当作"没有规则"处理，不报错。

## 类别树

- 运行时拉 `/site.json`，GM 缓存 7 天；拉不到重试 3 次，仍失败则在面板里提示并给重试入口。
- 拉不到时，已存的类别规则仍按徽章 ID 生效（只是展示名用不上）。
- **只有「所有等级」规则依赖这棵树**：没有这类规则时立刻就绪、马上过滤，首屏不等树。
- 下拉排列：「（所有等级）→（不带等级）→ 各等级子分类（缩进）」，无子分类的只给裸名字。
- 有子分类的分类标注「（不带等级）」，避免被当成整个大类。
- 父分类不在可见列表（受限或已删除）时按顶级展示，保证不丢项。
